# Contributing

Build with `nice -n 10 make` and test with `nice -n 10 make test` on macOS 14 or later with Apple's Command Line Tools or Xcode and Swift 6 or later. The rendering tests need a session where WebKit can start its content process.

Pull requests are welcome. Keep changes focused and include a way to check them. The maintainer reads issues.
